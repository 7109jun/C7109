# `Cmake7109.txt` 명세

## 목적
C7109 전용 선언형 빌드 DSL이다. CMake와 직접 호환되지 않으며 별도의 문법과 실행 모델을 가진다.

## 빌드 기능
구현체는 증분 빌드, 병렬 빌드, 캐시, 크로스 컴파일, 재현 가능한 빌드를 지원해야 한다. 명령행 옵션은 파일 설정을 덮어쓴다.

## 표현 대상
빌드 파일은 프로젝트, 타깃, 소스, include 경로, 의존성, 컴파일 옵션, 링크 옵션, 출력 경로, 빌드 구성, 대상 플랫폼을 표현할 수 있어야 한다.

## 의미 규칙
1. 입력과 출력의 관계로 빌드 그래프를 구성한다.
2. 입력·옵션·의존성이 변하지 않은 작업은 캐시를 재사용할 수 있다.
3. 병렬 빌드에서도 의존 작업의 순서를 보장한다.
4. 호스트와 크로스 컴파일 타깃을 구분한다.
5. 순환 의존성, 누락된 소스, 충돌 옵션, 출력 충돌을 진단한다.

## 개념 예시 (실제 문법으로 확정된 예제가 아님)
```text
project "Example"
target executable "app":
    sources:
        "src/main.c7"
        "src/math.c7"
```

## 미결정
정식 문법·키워드, 변수/조건/반복 지원, 사용자 명령 실행, 타깃 종류, 환경 변수, 기본 출력 디렉터리, 빌드 스크립트 보안 모델.
