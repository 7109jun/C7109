# C7109 파일 형식 명세 묶음
상태: 설계 초안 / 대상: C7109 1.x

포함 명세:
- `Cmake7109.txt`: C7109 전용 선언형 빌드 DSL
- `.cset7`: 컴파일러 및 빌드 환경 설정, TOML
- `.cr7`: 컴파일러·타깃·빌드 옵션·의존성 잠금, TOML
- `.l7`: ZIP 기반 라이브러리 패키지
- `.mp7`: 사람이 읽을 수 있는 텍스트 맵/리스팅 파일

MUST는 필수, SHOULD는 권장, MAY는 선택 사항을 뜻한다.
확정되지 않은 문법과 필드는 미결정으로 표시하며 표준인 것처럼 임의 확정하지 않는다.

공통: 텍스트는 UTF-8, 기본 줄바꿈은 LF, 경로는 `/`로 정규화한다.
무결성 해시는 별도 지정이 없으면 SHA-256을 사용한다.
