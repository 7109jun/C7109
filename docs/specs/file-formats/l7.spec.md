# `.l7` 명세

## 목적 및 컨테이너
`.l7`은 ZIP 기반 C7109 라이브러리 패키지 컨테이너다.

## 포함 정보
패키지는 라이브러리 바이너리, 메타데이터, 헤더, 의존성 정보, 라이선스, 대상 플랫폼 및 ABI 정보를 담도록 설계한다. 하나의 패키지에 여러 타깃의 바이너리를 포함할 수 있다.

## 압축 및 무결성
ZIP 압축을 지원하며 SHA-256 무결성 검증을 지원한다. 향후 서명 체계를 추가할 수 있도록 확장 가능해야 한다. SHA-256은 발행자 인증을 대신하지 않는다.

## 권장 디렉터리 예시 (내부 경로는 미확정)
```text
Example.l7
├── manifest.toml
├── include/Example.h7
├── lib/
│   ├── windows-x86_64/Example.lib
│   └── linux-x86_64/libExample.a
├── dependencies/
├── licenses/LICENSE
└── checksums.sha256
```

## 메타데이터 필드
최소 표현 대상: 패키지 이름, 버전, 의존성, 라이선스, 타깃, ABI. 메타데이터 파일명·직렬화 형식·필드 필수 여부는 미결정이다.

## 타깃 선택
설치 도구는 OS, CPU 아키텍처 및 ABI 호환성을 확인해야 한다. 호환 바이너리가 없으면 다른 플랫폼의 바이너리로 대체해서는 안 된다.

## 안전한 추출
경로 순회(`../`), 컨테이너 외부 경로, 엔트리 충돌을 방지해야 한다. 체크섬이 있으면 설치 전에 검증한다.

## 미결정
ZIP 버전/압축 알고리즘, 내부 경로, manifest 스키마, 바이너리 명명, 체크섬 형식, 서명 알고리즘, 크기 제한, ABI 호환성 규칙.
